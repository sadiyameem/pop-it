# Pop-It

# Description
- This is a simple pop-it where users will click on the circles and each time they are clicked and unclicked it will make a popping sound.

# Features
- Popping sound
- Background changing button

# Tools
- HTML
- CSS
- JavaScript
- https://mixkit.co/

# Challenge/Learned
- A challenge was getting the right sound since I was unable to get sounds from the site I normally use.
- I learned how to add shadow to the pop-it and change the shape.
